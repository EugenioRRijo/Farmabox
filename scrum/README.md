# Metodología Scrum - Servicio Comunitario

## Flujo de Trabajo

### Sprint Duration

- **2 semanas** por Sprint

### Roles (adaptados)

- **Product Owner**: Eugenio Rijo / Representante de la Facultad
- **Scrum Master**: Eugenio Rijo
- **Dev Team**: Eugenio Rijo (Full Stack)

## Artifacts

### Product Backlog

Ver `backlog/product_backlog.md` - Lista priorizada de todas las funcionalidades

### Sprint Backlog

Ver `sprints/sprint_X.md` - Funcionalidades seleccionadas para el Sprint actual

## Ceremonies

### Sprint Planning

- Seleccionar ítems del Product Backlog
- Definir Sprint Goal
- Estimar esfuerzo (Story Points)

### Daily Scrum (adaptado)

- Auto-revisión diaria de progreso
- Identificar blockers

### Sprint Review

- Demo de funcionalidad completada
- Feedback de stakeholders

### Sprint Retrospective

- ¿Qué salió bien?
  -¿Qué mejorar?
- Acciones para próximo Sprint

## Definition of Done (DoD)

✅ Código implementado  
✅ Tests unitarios passing (>80% coverage en shared logic)  
✅ Sin errores de linting  
✅ **Validación de Colisión Cero-Tolerancia funcional**  
✅ Documentado en código (JSDoc/comentarios)
